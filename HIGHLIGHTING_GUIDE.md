# Annotation Highlighting Guide

## Overview

The Markdown Annotations plugin provides real-time visual highlighting of annotated text in the Obsidian editor. The highlighting style is inspired by iA Writer's implementation, with distinct visual treatments for each annotation type.

## Visual Styles

### Human Contributions (@)

**Appearance**: Subtle green-to-blue gradient with a solid underline

**Colors**:
- Light mode: Soft green (#34a853) to blue (#4285f4) gradient
- Dark mode: Brighter green-blue tones for better visibility
- Underline: Semi-transparent green

**Use case**: Text written by human authors

**Example**:
```markdown
@John Doe: 0,50
```

### AI-Generated Text (&)

**Appearance**: Vibrant multi-color gradient reminiscent of Apple's Siri

**Colors** (left to right):
- Red (#ff453a)
- Orange (#ff9f0a) 
- Purple (#bf5af2)
- Indigo (#5e5ce6)
- Blue (#32ade6)

**Animation**: Subtle pulsing shimmer effect (3s cycle)

**Use case**: Content generated by AI assistants (ChatGPT, Claude, etc.)

**Example**:
```markdown
&Claude: 50,100
```

### Reference Material (*)

**Appearance**: Dimmed gray with reduced opacity

**Colors**:
- Light mode: Light gray with 70% opacity
- Dark mode: Slightly lighter gray with 65% opacity
- Underline: Dotted line for distinction

**Use case**: Quoted or referenced material from external sources

**Example**:
```markdown
*Smith et al. 2023: 150,200
```

## How It Works

### CodeMirror Extension

The plugin uses a CodeMirror 6 extension that:
1. Parses the document for annotation blocks
2. Validates the hash to ensure annotations are correctly positioned
3. Converts grapheme cluster indices to byte positions
4. Applies CSS decorations to the annotated text ranges

### Performance

- **Async parsing**: Document parsing happens asynchronously to avoid blocking
- **Incremental updates**: Only re-parses when document changes
- **Efficient positioning**: Uses grapheme-aware positioning for Unicode correctness

## Toggling Highlights

You can enable/disable visual indicators in settings:

1. Open **Settings → Markdown Annotations**
2. Toggle **Show visual indicators**
3. Reload files or restart Obsidian for changes to take effect

## Dark Mode Support

The plugin automatically adjusts colors based on your Obsidian theme:
- Light themes use softer, more subtle colors
- Dark themes use brighter, more vibrant colors for better contrast

## Browser Compatibility

The highlighting uses modern CSS features:
- Linear gradients
- RGBA colors with alpha transparency
- CSS animations (for AI gradient)
- Border styling

These features are supported in all modern browsers and Obsidian's Electron environment.

## Customization

### Custom CSS

You can override the default styles by adding custom CSS to your vault:

**Location**: `.obsidian/snippets/markdown-annotations-custom.css`

**Example** - Change human annotation to pure green:
```css
.md-annotation-human {
    background: rgba(0, 200, 0, 0.15) !important;
    border-bottom: 1px solid rgba(0, 200, 0, 0.4) !important;
}
```

**Example** - Disable AI animation:
```css
.md-annotation-ai {
    animation: none !important;
}
```

**Example** - Make references more visible:
```css
.md-annotation-reference {
    opacity: 1 !important;
    background-color: rgba(128, 128, 128, 0.2) !important;
}
```

After adding custom CSS:
1. Enable the snippet in **Settings → Appearance → CSS snippets**
2. Reload to see changes

## Troubleshooting

### Highlights not appearing

**Possible causes**:
- Visual indicators disabled in settings
- Invalid annotation block (hash mismatch)
- Annotation block not properly formatted

**Solutions**:
1. Check **Settings → Markdown Annotations → Show visual indicators** is enabled
2. Run command **Validate annotations in current file**
3. Ensure annotation block follows spec format

### Incorrect highlighting positions

**Possible causes**:
- Hash mismatch (annotations out of sync with text)
- Character encoding issues
- Grapheme cluster handling errors

**Solutions**:
1. Run validation command to check hash
2. Ensure text uses standard UTF-8 encoding
3. Recalculate annotation ranges (feature coming soon)

### Performance issues with large documents

**Possible causes**:
- Very large files with many annotations
- Complex emoji or Unicode characters

**Solutions**:
1. Split large documents into smaller files
2. Reduce number of annotation ranges
3. Disable visual indicators for specific large files

### Colors look wrong in dark mode

**Possible causes**:
- Custom theme interfering with styles
- CSS snippet conflicts

**Solutions**:
1. Try with default Obsidian theme
2. Disable custom CSS snippets temporarily
3. Check for CSS conflicts in developer console (Cmd/Ctrl+Shift+I)

## Technical Details

### CSS Classes

- `.md-annotation-human`: Applied to human author ranges
- `.md-annotation-ai`: Applied to AI-generated ranges
- `.md-annotation-reference`: Applied to reference material ranges

### Z-Index and Layering

Annotations are applied as decorations in the CodeMirror editor layer. Multiple overlapping annotations will blend together.

### Animation Performance

The AI shimmer animation uses CSS keyframes which are GPU-accelerated for smooth performance without impacting typing or scrolling.
